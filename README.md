# Roommate Harmony V2

**A web application designed to make shared apartment living easier.**

## The Problem

People who move into shared apartments often struggle to understand unwritten household rules. Different habits, expectations, and responsibilities can lead to misunderstandings between roommates.

## Research

The project is based on Week 3 and Week 4 user research, including two interviews and context mapping.

The interviews highlighted the importance of clearly communicating household rules, organizing shared chores, and discussing problems together.

## The Solution

Roommate Harmony helps residents understand and organize shared living arrangements.

### Main Features

1. **Home** — Overview of household tasks, roommates, and rules.
2. **Chores** — Assign and track household responsibilities.
3. **House Rules** — View and manage shared apartment rules.
4. **Roommates** — View household members and their preferences.
5. **Feedback** — Share suggestions and household concerns.

## Technologies

- PHP
- HTML5
- CSS3
- JavaScript
- JSON-based data storage

## Development Process

The V2 application was developed from a low-fidelity prototype informed by user interviews, context mapping, and design research.

## Local Setup

1. Install a PHP-compatible local web server.
2. Copy the application files into the web root.
3. Ensure the application has a protected, writable `data` directory.
4. Open the application in your browser.

For public deployment, server-side access controls and data protection must be configured.
